# Support

Use [GitHub Issues](https://github.com/atrx07/Sable-AI/issues) for reproducible bugs
and focused feature requests. Include Sable/Python versions, platform, installation
method, execution backend, reproduction steps and redacted output. Do not attach
real keys, private repository contents, config, sessions or traces without reviewing
them. There is no guaranteed response time or support SLA.

Security reports follow [SECURITY.md](SECURITY.md), not public bug forms. Provider
outages, model availability and account/quota issues belong to the provider unless
there is a reproducible Sable integration defect. Check local readiness with
`sable doctor .`; it is offline and needs no successful inference request.

See [CLI usage](docs/cli.md), [platform support](docs/platforms.md) and
[contributing](CONTRIBUTING.md) before reporting installation or development issues.
